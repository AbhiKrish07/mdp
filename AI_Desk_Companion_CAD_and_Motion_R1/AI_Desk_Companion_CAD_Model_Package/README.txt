AI DESK COMPANION — PRELIMINARY CAD PACKAGE (R0.1)

Start with AI_Desk_Companion_Assembly.step in a STEP-capable CAD package.
Module_*.step files are subassemblies. AI_Desk_Companion_Exploded.step is for exploded presentation.
The combined assembly STL contains overlapping assembly components; do NOT slice it as one print.
Individual STL files are included as preliminary part/envelope exports; inspect each before printing.
assembly_view.scad and build_cad.py are source/support files.

This is not manufacturing-ready CAD. Internal electronics are bounding-envelope placeholders; component part numbers,
materials, fasteners, wall thicknesses, tolerances, battery topology and servo models are not frozen.
The model has not been validated by FEA, physical stability tests, thermal tests, runtime tests or hardware fit checks.
Read the accompanying AI_Desk_Companion_Preliminary_CAD_Engineering_Report.pdf before fabrication.
